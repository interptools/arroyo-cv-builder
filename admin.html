System Health

Catch storage, email and AI problems before a customer does

💾 Cloud Storage (JSONBin)

Free bins hold about 100 KB. When full, the customer form starts deleting your oldest records to make room — so keep this below 80%.

Checking…

✉️ Email Usage This Month

EmailJS free plans cap how many emails you can send per month. This counter is kept in this browser, so treat it as a guide — your EmailJS dashboard is the real number.

— Assumed cap: / month

Duplicate protection is on: setting a status to Done a second time will not re-send the same email. Use the Send button in the submission if you truly need to send again.

🧪 Send a Test Email

Sends a real "CV is Ready" email to yourself using the exact same template, variables and GCash block your customers receive. The fastest way to check a template change before a customer sees it — and to confirm EmailJS is working at all.

A test uses one of your monthly allowance and appears in EmailJS → Email History like any other send. The subject is prefixed [TEST] so you can tell it apart. No customer record is touched.

🧪 Self-Service Test Run

Walks a fake order through the whole self-service flow against your real storage — creates it, attaches a GCash reference, approves it, then deletes it again. The fastest way to know the customer's Save & Print will actually unlock. Takes about ten seconds and touches none of your real orders.

Test orders are named TEST Customer, carry a 🧪 TEST badge, and are left out of your revenue figures. They delete themselves at the end of a run — the button above is only needed if a run is interrupted halfway.

🤖 AI Providers

AI features fall through a chain of providers. Test them here — if one is dead, the model name or API key inside that Cloudflare Worker most likely needs updating.
